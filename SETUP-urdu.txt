AL JANNAT POS - MULTI-DEVICE ONLINE CLOUD SETUP & UPDATE GUIDE
===================================================================

Yeh POS app ab mukammal "ONLINE CLOUD POS" ban chuki hai:
- Sab bhaiyon ke mobile par ek hi central database chalega.
- Ek bhai sale karega to dusre bhaiyon ke mobile par foran "Aaj ki sale" aur bills live update honge.
- 4-digit PIN login screen: Har bhai dukan ka PIN dale aur foran billing shuru kar de.
- Offline support: Agar kisi mobile par net thori der ke liye band bhi ho jaye to bill rukega nahi, net aate hi khud ba khud central database mein sync ho jayega!

===================================================================
1. GITHUB WARNING & API KEY RESOLUTION (Hal Kar Diya Gaya Hy)
===================================================================
Q: GitHub ne API key ki warning kyun di thi?
Ans: GitHub ka robot Google Cloud API keys ka pattern (AIzaSy...) detect karke automated alert bhejta hy. 

Firebase Web apps mein yeh API key public identifier hoti hy (jaise project ka address), yeh secret password nahi hoti. Asal security Firestore Rules se hoti hy jo humne firestore.rules mein set kar di hain.

LEKIN humne is warning ko mukammal khatam karne ke liye:
1. `index.html` se raw API key string ko remove kar diya hy, taake GitHub par koi warning ya alert na aaye.
2. Settings tab mein "Cloud API Key" ka option de diya hy jahan se aap key manage kar sakte hain.
3. Google Cloud Console mein key restrict karne ka tareeqa:
   - Link kholen: https://console.cloud.google.com/apis/credentials?project=aljannat-pos-pk
   - Apni API key par click karein.
   - "Set application restrictions" mein "Websites" chunein.
   - Website URL daalein: https://<aapka-username>.github.io/*
   - Is se yeh key dunya mein sirf aur sirf aap ki GitHub website par kaam karegi!

===================================================================
2. ONLINE CLOUD DATABASE (FIREBASE) ACTIVATION (Sirf 1 Baar)
===================================================================
Aap ke laptop par Google Firebase project humne already bana diya hai:
Project ID: aljannat-pos-pk
Project Name: Al Jannat POS

Bas 1 chhota sa aakhri step baki hai database on karne ke liye:
1. Browser mein yeh link kholen:
   https://console.firebase.google.com/project/aljannat-pos-pk/firestore
2. "Create database" button par click karein.
3. Location mein "asia-south1" (Mumbai/nearest) ya koi bhi default location chunein -> Next.
4. "Start in test mode" chunein -> Create / Enable.
Bas! Aap ka central cloud database ready hai aur 100% free chalega.

===================================================================
3. GITHUB PAR UPDATE KAISE KAREIN?
===================================================================

TAREEQA 1: Browser se (Sub se aasan tareeqa - 1 minute)
-------------------------------------------------------
1. Computer par github.com kholen aur apni repo kholen (aljannat-pos).
2. "Add file" -> "Upload files" par click karein.
3. Is folder (`d:\Softwares\AL JANNAT\aljannat-pos-mobile`) se ye files drag & drop karein:
   - index.html
   - sw.js
   - firestore.rules
   - manifest.webmanifest
   - SETUP-urdu.txt
4. Neeche green button "Commit changes" par click kar dein.
5. GitHub Pages 1 minute mein nayi app deploy kar dega!

TAREEQA 2: Git Terminal se
--------------------------
git add .
git commit -m "Fix API key exposure and add Cloud sync"
git push origin main

===================================================================
4. HAR BHAI KE MOBILE PAR KAISE CHALEGA?
===================================================================
1. Har bhai apne mobile ke Chrome browser mein dukan ka GitHub link khole:
   https://<aapka-username>.github.io/aljannat-pos/
2. Chrome menu (3 dots) par click karke "Add to Home screen" / "Install app" kar lein.
3. App kholte hi 4-digit PIN screen aayegi:
   - Default PIN: 1234
   - "Is phone par login yaad rakhein" tick laga rehne dein taake roz roz PIN na dalna pare.
4. Top header mein "🟢 Cloud Live" likha nazar aayega.
5. Ab jis mobile se bhi bill banega, sabhi mobiles par live update aayegi!

===================================================================
5. NAYA PIN KAISE SET KAREIN?
===================================================================
Settings tab mein ja kar "Dukaan ka Login PIN" se aap apni marzi ka koi bhi 4-digit PIN rakh sakte hain.
Agar kisi waqt screen lock karni ho to header mein bane "Lock" icon par tap karein.
